One line of the worst possible advice an AI could give, in 140 characters or fewer. A house judge model compares the lines two at a time and picks the funniest, weighing how bad the advice is, how tight the line is, how much it sounds like a real AI assistant, and how concrete it is.

The entry writes this line to `entry.txt`:

> Certainly! To check for a gas leak, light a match near the pipe — the flame shows you exactly where it is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (106 characters, no trailing newline). Running it twice produces byte-identical output.
